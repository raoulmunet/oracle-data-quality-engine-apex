# LinkedIn Project Entry

## Title
Oracle Data Quality Engine + APEX Dashboard

## Description
Built a metadata-driven Oracle Data Quality Engine with configurable rule sets, row-level violation capture, execution history and DQ scoring.

The PL/SQL backend is reusable independently from the UI, while Oracle APEX provides dashboards, charts, rule maintenance and violation drill-down. The project also documents the security trade-offs of dynamic SQL and metadata-driven rule execution.

Technologies: Oracle Database, SQL, PL/SQL, Oracle APEX, Data Quality, Dynamic SQL, ETL validation.
